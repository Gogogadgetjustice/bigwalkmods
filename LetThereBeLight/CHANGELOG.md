# Changelog

## 1.1.0 - Look at what the light did now 
- We got more default preset colors.
- We can now go back or forward in the preset colors with C/V or the mousewheel. 
- We got a F3 menu. 
- It's got custom intensity, distance, and bloom. 
- It's got setting custom RGB values for your light.
- It's got 3 save slots for that intensity, distance, and angle.
- We got far less overhead waste if the light isn't active.
- New icon based on another late 70s album cover. Go listen to Parliament.
