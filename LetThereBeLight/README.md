# Let There Be Light

It's basically your own private flashlight with a bunch of new customization options. 

If you prefer just using the torches, that's cool. You can skip this.

If you plan on annoying strangers, that's not cool. You can skip this and everything else. 

If you want a flashlight with less configuration but more teleportation mechanics, check out my other mod [Portals](https://old.thunderstore.io/c/big-walk/p/gogogadgetjustice/Portals/). 

## The F3 Customization Menu
Configuration Options include:

- the intesity of the light's circle. .5 - 30
- The range in meters of how far it projects out. 5 - 5000. 
- The Spotlight bloom's intensity 10 - 360

- RGB value for lights. Save as you cycle. 

- Save up to 3 different presets for the first intesity/range/bloom combo. Maybe you want to quick swap between a penlight, floodlight, and painting the island hot pink. Whatever combo you like without having to fiddle with three sliders.

- Enable/disable scrollwheel for color swapping.

## Controls

| Key | Action |
|-----|--------|
| **F** | Toggle light |
| **C** | Cycle colors one way |
| **V** | Cycle colors the other way |
| **Mousewheel up/down** | Cycle colors with your mouse hand |
| **F3** | Config Settings Menu Popup | 

## Requirements

- [BepInExPack_IL2CPP](https://thunderstore.io/c/big-walk/p/BepInEx/BepInExPack_IL2CPP/)

## Config

After first launch: `BepInEx/config/gogogadgetjustice.bigwalk.flashlight.cfg`
or the F3 button in game. Delete the cfg to reset to default.
