Press P to log the current player location.

It'll look like this.

- [Info   :Big Walk Location Logger] [Location] Position: X=-39.67, Y=97.31, Z=-649.60 | Rotation: Yaw=142.4┬░

that's all the locator dll does.

hotkey debug also includes pressing R to raycast 5m from the camera, dump every component (with full class name) , then up to 6 parent objects and dumps their components too.

press l to saved a location.
press k to teleport to that saved location.
persists between host sessions.

convenient if you're messing around a particular spot of the island and want to save a few minutes running back over every single time.
